# SAIF Case Viewer

A lightweight, interactive data viewer for exploring pathology reports and histological images in the SAIF (Self-reported race prediction in dermatopathology using AI for Fairness) project.

## Features

### 🔬 Dual Modality Support
- **Pathology Reports**: View patient demographics, clinical data, diagnoses, and experiment metadata
- **Histological Images**: Browse whole-slide images, attention maps, and tile-level analysis

### 📊 Interactive Visualization
- Multi-encoder attention map comparison (SP22M, UNI, GigaPath, Virchow)
- UMAP projections for tissue morphology exploration
- Tile-level analysis with attention score heatmaps
- Side-by-side combined view of images and reports

### 🔍 Advanced Filtering
- Filter by self-reported race, experiment version, and encoder
- Search by case ID, patient ID, or other identifiers
- View race distribution statistics

## Installation

### Prerequisites
- Python 3.8 or higher
- Access to SAIF dataset and preprocessed features

### Setup

1. **Clone the repository** (if not already done):
```bash

```

2. **Install dependencies**:

Ensure your data is organized as follows:

```
│   │   └── coordinates/  # .csv files
│   ├── UNI/
│   ├── GigaPath/
│   └── Virchow/

│   └── skin/
```

## Usage

### Quick Start

Launch the viewer from the case_viewer directory:

```bash
streamlit run app.py
```

The application will open in your default web browser at `http://localhost:8501`.

### Navigation

1. **Home**: Overview of the project and dataset statistics
2. **Case Browser**: Search and filter cases with metadata
3. **Image Viewer**: View slide images, attention maps, and tile analysis
4. **Report Viewer**: Access pathology reports and clinical information
5. **Combined View**: See images and reports side-by-side

### Workflow Example

1. Navigate to **Case Browser**
2. Filter by race (e.g., "White", "Black")
3. Select experiment version (e.g., "Exp3")
4. Click "View Details" on a case
5. Explore in **Combined View** to see both modalities

## Data Requirements

### Metadata File
The viewer expects a metadata CSV file at:
```
data/self_reported_race/skin/master_metadata.csv
```

Expected columns (flexible, uses alternative names):
- `case_id` or `slide_id`: Unique slide identifier
- `patient_id` or `mrn`: Patient identifier
- `race` or `self_reported_race`: Demographic group
- `diagnosis` or `primary_diagnosis`: Pathology diagnosis
- `experiment` or `exp_version`: Dataset version (Exp1/Exp2/Exp3)
- `encoder` or `feature_encoder`: Model encoder name

### Feature Files
For each encoder (e.g., SP22M):
- **Features**: `data/{encoder}/features/{slide_id}.pth` (PyTorch tensors)
- **Coordinates**: `data/{encoder}/coordinates/{slide_id}.csv`

### Attention Maps
Generated by running `get_attention.py`:
```
slide_experiments/skin/{encoder}/attention_maps/{slide_id}_{race}_attention.png
```

### UMAP Projections (Optional)
For advanced visualization:
```
Emb_Viz/marimo_metadata.csv
```

### Adding New Features

1. Create a new module in `viewers/` or `utils/`
2. Import and integrate in `app.py`
3. Test locally with sample data
4. Commit and push to `case_viewer_dev` branch

### Customization

**Change Data Paths**: Edit paths in `utils/data_loader.py`:
```python
self.data_root = Path("your/custom/path")
self.metadata_file = Path("your/metadata.csv")
```

**Add New Encoders**: Update encoder lists in:
- `app.py` (encoder selection dropdown)
- `utils/data_loader.py` (default encoder list)

**Modify Layout**: Edit Streamlit components in `app.py` and viewer modules

## Troubleshooting

### "Metadata file not found"
- Verify the path to `master_metadata.csv`
- Check that you're running from the correct directory
- Update `self.metadata_file` in `data_loader.py`

### "No attention maps found"
- Run `get_attention.py` to generate attention maps:
  ```bash
  python slide_experiments/code/get_attention.py --encoder SP22M
  ```

### "Features not loading"
- Ensure `.pth` files exist in `data/{encoder}/features/`
- Check file permissions
- Verify PyTorch installation

### Port Already in Use
If port 8501 is busy:
```bash
streamlit run app.py --server.port 8502
```

## Performance Tips

- **Large Datasets**: Use filtering to limit displayed cases
- **Memory**: Close unused tabs in the viewer
- **Speed**: Enable Streamlit caching (already configured)
- **Remote Access**: Use SSH tunneling for HPC access:
  ```bash
  ssh -L 8501:localhost:8501 user@hpc.server.edu
  ```
